# EXECUTIVE_SCENARIO_LAB

## FINALIDADE

Este documento define oficialmente o laboratório executivo de simulação institucional da plataforma Illumine.

O EXECUTIVE_SCENARIO_LAB torna-se o ambiente oficial de:

* simulação executiva;
* stress testing;
* projeção institucional;
* análise de impacto;
* forecast estratégico;
* avaliação de expansão;
* análise de runway;
* propagação causal;
* simulação de crescimento;
* simulação de retração;
* modelagem de risco empresarial.

A plataforma Illumine deixa oficialmente de operar apenas como:

* plataforma interpretativa;
* painel analítico;
* sistema de advisory.

A Illumine passa a operar também como:

* laboratório executivo de decisão;
* plataforma de simulação institucional;
* ambiente de forecast causal;
* motor executivo preditivo;
* simulador empresarial integrado.

⸻

## GOVERNANÇA DO SCENARIO LAB

Toda simulação executada no EXECUTIVE_SCENARIO_LAB deverá obedecer obrigatoriamente:

* MASTER_ARCHITECTURE.md
* MASTER_CAUSAL_ENGINE.md
* SCENARIO_SIMULATION_ENGINE.md
* OPERATIONAL_INTELLIGENCE_LAYER.md
* CASH_FLOW_INTELLIGENCE_LAYER.md
* EXECUTIVE_ADVISORY_ENGINE
* CALIBRATION & STABILITY LAYER
* WEIGHTED CAUSAL INFERENCE LAYER

Nenhum componente React poderá:

* calcular projeções;
* inferir causalidade;
* recalcular indicadores;
* gerar advisory;
* gerar forecast;
* criar stress local;
* interpretar runway;
* criar recomendações executivas paralelas.

Toda inteligência deverá permanecer:

* centralizada;
* institucional;
* causal;
* validada;
* moderada;
* propagada via SSOT.

⸻

## ESTRUTURA DO LAB

O laboratório deverá possuir obrigatoriamente:

### 1. SCENARIO CONTROL PANEL

Painel institucional de parâmetros executivos.

A UI poderá:

* parametrizar;
* controlar;
* comparar;
* visualizar cenários.

A UI NÃO poderá:

* calcular;
* inferir;
* interpretar.

Parâmetros mínimos:

* crescimento de receita;
* retração;
* CMV;
* OPEX;
* EBITDA;
* headcount;
* dívida;
* aporte;
* CAPEX;
* inadimplência;
* recebíveis;
* runway;
* fornecedores;
* funding.

⸻

### 2. INSTITUTIONAL PROJECTION PANEL

Painel oficial de projeção institucional.

Exibir:

* runway projetado;
* stress projetado;
* resiliência;
* elasticidade;
* continuidade;
* pressão estrutural;
* pressão operacional;
* pressão de tesouraria;
* growth sustainability;
* dependence score.

⸻

### 3. ADVISORY DELTA ENGINE

Exibir:

* o que mudou;
* por que mudou;
* quais causalidades propagaram;
* quais riscos surgiram;
* quais falsos positivos foram bloqueados;
* quais dimensões deterioraram.

A plataforma deverá mostrar:

* causalidade propagada;
* impacto longitudinal;
* deterioração incremental;
* evolução do stress.

⸻

### 4. BEFORE VS AFTER COMPARISON

O LAB deverá permitir comparação entre:

**ESTADO BASE**
* dados reais auditados.

**ESTADO PROJETADO**
* dados simulados propagados pela engine.

Comparar:

* BP;
* DRE;
* Caixa;
* Runway;
* Advisory;
* Scores;
* Resiliência;
* Continuidade.

⸻

### 5. RISK PROPAGATION MAP

A plataforma deverá exibir visualmente:

Exemplo:
`crescimento → capital de giro → runway → pressão de caixa → stress estrutural → advisory executivo`

A UI deverá mostrar:

* origem do stress;
* propagação causal;
* deterioração incremental;
* impactos dominantes.

⸻

## PROJEÇÕES PROIBIDAS

* projetar crescimento sem runway;
* ignorar caixa;
* ignorar capital de giro;
* ignorar elasticidade;
* ignorar funding;
* ignorar runway crítico;
* ignorar propagação causal;
* gerar forecast otimista artificial;
* liberar expansão destrutiva.
