# Guia da Jornada do Conselho (Board Journey Guide)

Este guia orienta o comitê executivo e os conselheiros na utilização da Jornada Guiada de Conselho da plataforma Illumine.

## Lançando a Apresentação Guiada

1. Acesse o **Client Executive Workspace**.
2. Clique no painel **Board Journey** e selecione **Iniciar Apresentação**.
3. O sistema entrará em tela cheia apresentando os slides oficiais mapeados passivamente do runtime.

## BOARD_EVIDENCE_MODE

Durante as apresentações, os conselheiros podem ativar o painel de **Evidências** na barra de controle inferior. Esse painel exibe:
- O hash SHA-256 do dataset importado para garantir a integridade dos dados expostos.
- Os parâmetros ativos no motor de calibração do runtime.
- O Trace ID para depuração e auditabilidade técnica.
- Alertas ou restrições fiduciárias ativas.

*A ativação deste modo não realiza interpretação local de dados na UI, servindo estritamente como visualizador direto de metadados fiduciários do runtime.*
