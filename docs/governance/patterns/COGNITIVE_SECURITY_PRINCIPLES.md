# Cognitive Security Principles™

Princípios de orientação máxima para o desenvolvimento de agentes, engines e interfaces na Illumine OS™.

1. **Sovereignty Above All:** O contexto do cliente (Tenant) é o limite físico, lógico e abstrato de qualquer dedução de inteligência. A IA trabalha **exclusivamente** no universo autorizado.
2. **Deterministic Observability:** O não-determinismo dos modelos generativos deve ser encapsulado e monitorado. Toda saída probabilística deve ter uma cadeia determinística de evidências.
3. **Fail-Closed Reasoning:** Na ausência de contexto institucional provado ou em caso de contradição de permissões, a execução cognitiva deve ser abortada imediatamente (Zero Trust AI).
4. **Separation of Cognition and Governance:** Agentes que geram inteligência nunca podem ser os mesmos que aprovam sua liberação. O Trust Gate deve ser uma entidade isolada no fluxo.
