# Executive Constitution Engine

Este documento atua como o **Painel de Controle Permanente** do compilador e framework visual executivo da plataforma Illumine Governance. 

O projeto original `HG-002` (antes uma refatoração de UI) evoluiu para o **Executive Constitution Engine**. Nele, não operamos mais alterações isoladas por página, mas sim por meio da institucionalização contínua de **Domínios Constitucionais** (Constitutional Domains) na Camada Canônica.
