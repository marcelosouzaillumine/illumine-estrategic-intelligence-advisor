# ADR-007: Arquitetura SSOT para Demonstrações Financeiras

- **Status**: **Aprovado**
- **Data**: 2026-07-29
- **Decisor / Autor**: Arquiteto-Chefe / Comitê Arquitetural
- **Domínio**: Finance Core Pipeline & Data Architecture

---

## 📑 Contexto

Garantir que todas as visões financeiras da plataforma (oficiais, gerenciais e analíticas) consumam uma única fonte de dados de lançamento contábil, eliminando discrepâncias numéricas entre relatórios.

---

## 🎯 Decisão

1. **Adoção do Fluxo Unidirecional de Dados (SSOT Pipeline)**:
   $$\text{Firestore Raw Data} \longrightarrow \text{Normalization Layer} \longrightarrow \text{Financial Engines} \longrightarrow \text{Canonical Models} \longrightarrow \text{Adapters} \longrightarrow \text{Pages}$$
2. **Camada de Leitura Unificada**:
   - Toda leitura de lançamentos contábeis (`financial_entries`) deve ser realizada via `useAnnualFinancialData` ou `FiduciaryRuntimeAdapter`.
   - Nenhuma visão analítica ou gerencial pode re-implementar parsing bruto de banco de dados.

---

## 📊 Consequências

- Garantia de paridade numérica absoluta entre o DRE Contábil, DRE Gerencial, Balanço Patrimonial e DFC.
