# HG-002A — Executive Cognitive Architecture (ECA)

## Objective
Before performing any visual canonicalization, redesign the cognitive architecture of each page.
The purpose of this program is **NOT** to replace components.
The purpose is to ensure that every page communicates with executive clarity, following the Executive Visual Constitution and the Executive Decision Experience principles.
Only after the page architecture is approved may visual canonicalization begin.

---

## Fundamental Principle
Do not think as a Frontend Developer.
Do not think as a UI Designer.
Think as:
- CEO
- CFO
- Board Member
- Investor
- Senior Advisor

Ask:
*"If I had only 30 seconds, would this page naturally guide me toward the right decision?"*

If the answer is "no", the page architecture must change.

---

## Phase 1 — Cognitive Classification
Before changing anything, classify the page.
Exactly ONE category:
- Strategic
- Executive Dashboard
- Financial Analysis
- Governance
- Simulation
- Operational
- Configuration
- Workflow
- Approval
- Registry
- Institutional
- Public

Each category has a different cognitive flow.

## Phase 3 — Information Hierarchy
Identify:
1. Primary Information
2. Secondary Information
3. Support Information
4. Hidden Technical Information

*Nothing should compete visually with executive decision-making.*

---

## Phase 4 — Component Mapping
Only now map each section to canonical components.

Examples:
- `ExecutiveSurface`
- `ExecutiveHeading`
- `ExecutiveMetricCard`
- `ExecutiveChart`
- `ExecutiveTable`
- `ExecutiveAccordion`
- `ExecutiveNarrative`
- `ExecutiveInsight`
- `ExecutiveRiskCard`
- `ExecutiveBadge`
- `ExecutiveEmptyState`

*No local implementations are allowed.*

---

## Phase 5 — Executive Reading Flow
Validate:
Can an executive understand the page in:
- 10 seconds?
- 30 seconds?
- 2 minutes?

If not: **Reorganize.**
*Never compensate poor hierarchy with colors or typography.*

---

## Phase 6 — Visual Canonicalization
Only after the architecture is approved:

Remove:
- hardcoded colors
- manual borders
- manual shadows
- manual radius
- local badges
- raw typography

Replace everything using the Executive Design System.

---

## Phase 7 — Executive QA
Validate:
- [ ] Cognitive hierarchy
- [ ] Decision flow
- [ ] Information grouping
- [ ] Component consistency
- [ ] Typography
- [ ] Contrast
- [ ] Spacing
- [ ] Accessibility
- [ ] Responsiveness
- [ ] Executive visual quality

*Only after all gates pass may the page be certified.*

---

## Workflow Enforcement & Deliverables

Nenhuma página deve ser refatorada diretamente. Primeiro ela deve ser “redesenhada” em nível executivo.
Antes de qualquer linha de código, o agente deve entregar o seguinte ciclo de vida:

`Página Atual` 
↓
`Diagnóstico Cognitivo`
↓
`Nova Arquitetura Executiva`
↓
**`Aprovação Humana`**
↓
`Canonicidade Visual`
↓
`Implementação`
↓
`QA Executivo`

Para cada página, produza um artefato contendo:
1. **Executive Diagnosis:** Current weaknesses.
2. **Proposed Executive Architecture:** New information flow.
3. **Component Mapping:** Canonical components to be used.
4. **Visual Changes:** Only visual changes. No business logic.
5. **Migration Risk:** SAFE | MEDIUM | HIGH.
6. **Approval Required:** Do not modify the page until the Executive Architecture has been explicitly approved. Architecture first. Canonicalization second. Implementation third.
