# ADR-073: Architecture Observatory (AOB v1.0)

## Status
Homologado & Ativo

## Contexto
Com a validação via Architecture Linter (ALC v1.0) e a chancela via Architecture Certification Framework (ACF v1.0), tornou-se necessário elevar a governança da IERA v1.0 para o nível de **Observabilidade e Telemetria Visual**.

A arquitetura precisava deixar de ser apenas validada sob demanda e passar a ser continuamente visualizada, navegável e auditável em relatórios multiformato (JSON, Markdown, HTML) em cada ciclo de release.

## Decisão
1. Instituir o subsistema **Architecture Observatory (AOB v1.0)** em `packages/tooling/architecture-observatory/`.
2. Publicar a especificação canônica em [`docs/ARCHITECTURE_OBSERVATORY.md`](file:///Users/marcelosouza/Documents/illumine-strategic-governance-advisor/docs/ARCHITECTURE_OBSERVATORY.md).
3. Implementar os 6 Dashboards de Observabilidade:
   - `Dependency Graph`
   - `Experience Map`
   - `Capability Map`
   - `Knowledge Graph`
   - `Architecture Coverage`
   - `Architecture Health`
4. Disponibilizar o comando CLI oficial: `npm run architecture:observatory`.
5. Determinar que a geração do snapshot de observabilidade é **automática a cada release no CI/CD**, salvando artefatos de telemetria em `docs/reports/architecture-observatory/`.

## Consequências
* **Positivas**:
  - Visibilidade total do grafo de dependências, experiências, capacidades e rastreabilidade causal.
  - Indicadores de saúde e cobertura (Health Score 100/100) atualizados a cada release.
  - Exportação nativa em JSON e Markdown para consumo por dashboards de monitoramento.
* **Negativas / Cuidados**:
  - Requer a execução do script de observabilidade ao final de grandes atualizações para manter a telemetria sincronizada.
