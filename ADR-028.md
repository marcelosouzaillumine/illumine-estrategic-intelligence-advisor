# ADR-028 — Agent Decision Learning Architecture

> **Status**: Approved  
> **Date**: 2026-07-29  
> **Context**: Wave 15B Autonomous Executive Agent Runtime  
> **Scope**: Episodic Decision Memory & Continuous Learning

---

## 1. Context & Problem Statement

Para transformar decisões executivas passadas em memória organizacional auditável e permitir que o sistema aprenda com os resultados reais, a arquitetura necessita de uma estrutura episódica de registro.

---

## 2. Decision: Episodic Memory in DecisionRecord

Fica estabelecido pelo Architecture Review Board (ARB) que:

1. **Estrutura do DecisionRecord**: Toda deliberação humana sobre uma recomendação executiva será registrada de forma imutável em `@illumine/organizational-memory` através da entidade `DecisionRecord` ($Contexto \rightarrow Recomendação \rightarrow Evidências \rightarrow Decisor Humano \rightarrow Resultado Real \rightarrow Aprendizado$).
2. **Loop de Calibração Preditiva**: O resultado real medido gerará um evento de aprendizado em `@illumine/decision-learning` para recalibrar a distribuição de probabilidades do agente sem mutação de código em runtime.

---

## 3. Consequences

- A plataforma acumula memória institucional imutável que sobrevive à rotatividade da gestão.
- Evolução contínua da acurácia das recomendações dos agentes.
