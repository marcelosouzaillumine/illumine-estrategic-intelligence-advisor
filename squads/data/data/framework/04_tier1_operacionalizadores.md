## Churn Signals

Mehta identifica sinais precoces de churn:

### Leading Indicators (Agir Imediato)

```
⚠️ Login decrease >50% mês-a-mês
⚠️ Champion deixou a empresa
⚠️ Ticket de suporte crítico sem resolução
⚠️ Não participou de renewal call
⚠️ Pediu exportação de dados
```

### Lagging Indicators (Já é tarde)

```
🚨 Pediu cancelamento
🚨 Contratou concorrente
🚨 Não renovou
```

## Community Metrics

### Métricas de Participação

| Métrica | Fórmula | Benchmark CMX |
|---------|---------|---------------|
| **MAU** | Active members / Total members | 10-20% |
| **DAU** | Daily active / Total | 1-5% |
| **Stickiness** | DAU / MAU | 5-20% |

## Filosofia Central

> "Completion rate de MOOCs é 6%. Cohort-based courses chegam a 96%. A diferença é design, não conteúdo."

Kao argumenta que o problema não é qualidade do conteúdo, mas modelo de entrega:

```
MOOC (Falho):
- Self-paced (sem urgência)
- Sozinho (sem accountability)
- Passivo (assistir vídeos)
- Baixo commitment ($20)

CBC (Funciona):
- Fixed timeline (urgência)
- Cohort (accountability social)
- Ativo (projetos, discussões)
- High commitment ($500-5000)
```

## State Change Method

Técnica para manter engajamento em sessões ao vivo:

```
Mudar modalidade a cada 5-10 minutos:

→ Lecture (5 min)
→ Chat engagement (2 min)
→ Poll/quiz (2 min)
→ Breakout rooms (10 min)
→ Share back (5 min)
→ Q&A (5 min)
→ Solo reflection (3 min)
→ Repeat...
```

## Completion Rate Optimization

### Por que MOOCs falham (6% completion)

| Fator | Problema |
|-------|----------|
| Sem deadline | "Faço depois" forever |
| Sem peers | Sem pressão social |
| Baixo preço | Baixo commitment |
| Passivo | Fácil desengajar |
| Sem feedback | Não sabe se está aprendendo |

### Como CBCs resolvem (96% completion)

| Fator | Solução |
|-------|---------|
| Fixed dates | Urgência real |
| Cohort | Accountability social |
| Premium price | Skin in the game |
| Active learning | Impossível ser passivo |
| Peer feedback | Validation constante |
