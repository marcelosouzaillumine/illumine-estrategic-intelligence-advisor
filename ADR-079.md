# ADR-079 — Data Lineage Governance Standard

> **Status**: Approved  
> **Date**: 2026-07-30  
> **Context**: Wave 18.4 Enterprise Intelligence Data Fabric (EIDF v1.0)  
> **Scope**: Data Lineage Traceability & Governance Standard

---

## 1. Context & Problem Statement

Garantir que toda evidência, indicador, insight e recomendação no **Executive Workspace** seja 100% auditável e rastreável até a fonte de dados primária.

---

## 2. Decision: Data Lineage End-to-End

Fica estabelecido pelo Architecture Review Board (ARB) a obrigatoriedade do contrato `DataLineageTrace`:

`Data Source → Transformation → Business Metric → Executive Insight → Executive Recommendation`

---

## 3. Consequences

- 0 indicador exibe valor numérico sem ID de origem e data da carga.
- Rastreabilidade fiduciária completa para auditoria de conselho.
