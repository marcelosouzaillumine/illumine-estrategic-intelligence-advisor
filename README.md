# Illumine Advisor

Strategic advisory application generated from AI Studio and bootstrapped for Synkra AIOX workflow.

View your app in AI Studio: https://ai.studio/apps/ef086d54-5c25-444a-bc16-5c7264f7cde5

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
