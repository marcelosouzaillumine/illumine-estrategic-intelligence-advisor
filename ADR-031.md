# ADR-031 — Agent Performance Measurement Standard

> **Status**: Approved  
> **Date**: 2026-07-29  
> **Context**: Wave 15C Executive Simulation & Pilot Validation  
> **Scope**: Performance Benchmarking & Agent Scoring

---

## 1. Context & Problem Statement

Para avaliar objetivamente a performance individual e coletiva dos 12 agentes executivos durante as simulações, é necessário um padrão quantitativo e auditável de benchmarking.

---

## 2. Decision: The Agent Performance Registry Standard

Fica estabelecido pelo Architecture Review Board (ARB) que:

1. **`AgentPerformanceRegistry`**: Todos os resultados de simulação de pareceres serão registrados no `AgentPerformanceRegistry`.
2. **Métricas de Desempenho Medidas**: Serão acompanhadas obrigatoriamente a Acurácia de Recomendação (`Recommendation Accuracy`), Taxa de Aprovação Humana (`Approval Rate`), Acurácia Preditiva de Impacto (`Impact Prediction Accuracy`) e o Score de Colaboração Transversal (`Cross Agent Collaboration Score`).

---

## 3. Consequences

- Baseline quantitativa comparativa de performance para cada agente.
- Identificação de oportunidades de calibração contínua dos modelos preditivos.
